Malhae Done

Daily email location

Malhae Daily uses your phone's GPS for the weather and the 06:00 and 20:00 send times.

Location the emails use

Not set yet (the emails use Seoul)

1. Connect to GitHub (once)

  1. On GitHub, open Fine-grained tokens → Generate new token. Name it Malhae location and set Expiration to the longest it allows.
  2. Under Repository access, choose Only select repositories → malhae.
  3. Under Permissions → Repository permissions, set Variables to Read and write. Nothing else.
  4. Tap Generate token, copy it, paste it below and tap Save, then allow location.

2. Keep it updated by itself (Android)

  1. Install MacroDroid from the Play Store (free).
  2. Add a macro. Trigger: Date/Time → Day/Time, at 15:00 and 21:00, every day.
  3. Action: Applications → Open Website, with this link, in Chrome:

The emails pick up the place a few hours before each send, so 15:00 covers the evening brief and 21:00 the next morning's. Give MacroDroid permission to open apps over others if it asks.

Your position is rounded to about 11 km and saved with its town name (from BigDataCloud's free lookup) in the MALHAE_LOCATION variable of your public repository, so the town can show in its Actions logs. The token stays on this phone.
