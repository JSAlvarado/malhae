Set-up (once)

  1. On GitHub, create a fine-grained token: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Account permissions, set Gists to Read and write. It needs nothing else.
  2. Paste the token here and tap Save. It stays on this phone only.
  3. Tap Update my location now and allow location. Malhae makes a secret gist for it and shows its ID below.
  4. In the malhae repository: Settings → Secrets and variables → Actions → New repository secret, name MALHAE_LOCATION_GIST, value: the gist ID.

Gist ID (the secret's value)

Your location is rounded to about 1 km. It goes only to your own secret gist, and its town name comes from BigDataCloud's free lookup. The Actions logs never show it. The emails can only use the last place your phone sent, so open Malhae when you arrive somewhere new.
